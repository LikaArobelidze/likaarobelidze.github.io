# Lika Arobelidze — Photography

პორტფოლიო საიტი. სტატიკურია — არანაირი სერვერი, ბაზა ან build არ სჭირდება.

## რა სად დევს

```
index.html            მთელი საიტი (HTML + CSS + JS ერთ ფაილში)
assets/photos/        80 ფოტო სრული ზომით (lightbox იყენებს)
assets/thumbs/        80 შემცირებული ვერსია (გალერეა იყენებს — სწრაფი ჩატვირთვა)
assets/video/         6 ვიდეო
assets/hero/          მთავარი ეკრანის ცალკე კადრი (გალერეაში არ ჩანს)
assets/og.jpg         სურათი, რომელიც ლინკის გაზიარებისას ჩნდება (1200×630)
assets/icon-*.png     საიტის ხატულა (ბრაუზერის ჩანართი, მთავარ ეკრანზე დამატება)
```

## მისამართი

საიტი განკუთვნილია მისამართისთვის **https://likaarobelidze.github.io** —
ეს მისამართი უკვე ჩაწერილია `index.html`-ის თავში (`og:url`, `og:image`, `canonical`).
სწორედ ის აკონტროლებს, თუ როგორ გამოჩნდება ლინკი WhatsApp-ში, Facebook-სა და Messenger-ში.

თუ ოდესმე სხვა მისამართზე გადაიტანთ, `index.html`-ში Ctrl+H-ით ჩაანაცვლეთ
`likaarobelidze.github.io` ახლით — თორემ გაზიარებისას სურათი აღარ ჩაიტვირთება.

## ლოკალურად ნახვა

`index.html`-ზე ორმაგი დაწკაპუნება. ცვლილების შემდეგ ბრაუზერში **Ctrl+F5**.

## ფოტოს შეცვლა

გალერეის თითოეულ ფოტოს ორი ფაილი აქვს ერთი და იმავე სახელით:
`assets/photos/caucasus-05.jpg` (დიდი) და `assets/thumbs/caucasus-05.jpg` (პატარა).
ორივე უნდა შეიცვალოს, თორემ გალერეაში ერთი ფოტო გამოჩნდება, გადიდებისას კი სხვა.
